Arquitectura de esta etapa

El chat propone; el usuario confirma; el ejecutor controla.

Antes de incorporar un modelo, validamos el mismo circuito que recibirá sus respuestas. Así aislamos la lógica GIS de la futura conexión con IA.

Contrato antes que proveedor

Una respuesta que la interfaz pueda entender y validar.

El contrato desacopla el widget de OpenAI, Azure OpenAI u otro motor. La UI consume una estructura propia del proyecto.

Request del widget
{ "message": "[mock:show-mina]", "conversationId": "session-123", "context": { "experience": "GIS_QB", "mapId": "...", "visibleLayers": [] } }
Response del servicio
{ "message": "Acción preparada.", "actions": [{ "type": "load_portal_item_layer", "portalItemId": "805596...aaf", "layerId": "asistente-imagen-mina", "opacity": 1, "zoom": true }], "requestId": "req-456" }
El texto se muestra. La acción se valida. Solo después se ejecuta contra el mapa.

Confirmación explícita

El usuario pulsa la propuesta antes de que el widget modifique el mapa.

Mapa inicialmente vacío

La operación de mostrar sabe crear la capa; no depende de que viva previamente en el Web Map.

Operación repetible

Si la capa ya existe, se reutiliza, actualiza su estado y vuelve a su extensión.

Seguridad por diseño

El control se construye antes del endpoint de IA.

El mock no es solo una ayuda visual: permite probar las fronteras de seguridad que también gobernarán las respuestas reales.

Guardrails activos

✓Sin secretos en React ni config públicaCopilot Studio y Entra permanecen desactivados en esta etapa.
✓Lista cerrada de Portal ItemsSolo IMAGEN_MINA e IMAGEN_TMF pueden cargarse.
✓Lista blanca de acciones y capasNo se ejecuta código, URL ni consulta arbitraria.
✓Validación de esquemaToda respuesta se considera entrada no confiable.
✓Confirmación humanaLa recepción de una propuesta no produce efectos por sí sola.

Definition of Done

Probar el comportamiento del mapa, no solo el mensaje.

La demostración debe ser repetible tanto con un Web Map vacío como con capas ya cargadas.

A

Contrato

Acción válida, tipo desconocido, parámetros incompletos e Item ID no autorizado.

B

Confirmación

La respuesta crea una propuesta visible y el mapa no cambia antes del clic.

C

Mapa vacío

La capa se crea desde Portal, termina de cargar y se navega a su fullExtent.

D

Repetición

Volver a mostrar reutiliza la misma capa y no agrega duplicados.

E

Seguridad

Allowlist estricta, contenido escapado, sin secretos y mensajes de error sanitizados.

F

Entrega

Compila con Node 24, funciona en localhost y queda exportado para Git y Netlify.
